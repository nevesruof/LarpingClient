Macros

Keys that send a command or a chat message.

Open the Macros page in the client menu and add a macro. Pick a key and type what it sends: a command like /home or /spawn, or a normal chat message.

  • Press the key in game and Larp sends it, exactly as if you typed it.
  • Macros are saved in config/larpclient-macros.json.

Some servers limit how fast you can send messages. Don't spam macros or you might get kicked.
