Troubleshooting

Fixes for the most common problems.

The game crashes on start#

  • Check that Fabric API is the 1.21.11 version and that there's only one copy of it.
  • Check you're launching the Fabric 1.21.11 profile, not vanilla or another version.
  • Remove other mods to find a conflict, especially ones that change the title screen, menus or HUD.
  • The crash report is in .minecraft/crash-reports; the latest log is .minecraft/logs/latest.log.

The menu doesn't open#

Another mod may use Right Shift. Change the key in Options → Controls → Larp Client, or use the Client button on the title screen.

Low FPS#

Install the recommended mods, turn on FPS Boost, lower Cosmetic FPS to 30 and turn on Reduced menu effects in Settings.

I can't see my cosmetics#

Press F5: cosmetics are hidden in first person unless you turn on Show in first person in their settings. Other players don't see them.

Discord status doesn't show#

  • Use the Discord desktop app, not the browser.
  • In Discord, turn on User Settings → Activity Privacy → Share my activity.
  • Check the Application ID and that the asset is named exactly logo.

My settings reset#

If the game closes by crashing, the last changes may not be saved. Save a profile as a backup.
