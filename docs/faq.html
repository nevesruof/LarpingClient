FAQ

Answers to common questions.

How do I get Larp Client?#

Larp Client is private and still in development, so it isn't public yet. Message Take and you'll get access.

Is Larp Client allowed on servers?#

Larp only changes what you see on your own screen. It has no combat, movement or auto-click modules, so it plays like any other visual client. Each server sets its own rules, so check theirs if you are unsure.

Can other players see my cosmetics?#

No. Cosmetics are drawn on your screen only. Press F5 to see them on yourself.

How do I open the menu?#

Press Right Shift in game, or click Client on the title screen. You can change the key in Options › Controls › Larp Client.

Does it work with Sodium and other performance mods?#

Yes. Larp is made to run next to Sodium, Lithium and Entity Culling, and they are the first mods we recommend. With Iris shaderpacks, some 3D effects can look different depending on the pack.

Which Minecraft versions are supported?#

Minecraft 1.21.11 with Fabric Loader 0.18.1 or newer, Fabric API and Java 21. Forge, NeoForge and older versions are not supported.

Where are my settings saved?#

In your config folder: larpclient.json for settings, larpclient-profile-1.json to -3 for profiles, and larpclient-waypoints.json and larpclient-macros.json. Copy them to move your setup to another PC.

The Music Player doesn't show the album cover.#

The Music Player reads Windows media controls, so it only works on Windows. If the cover still doesn't show, see Music player for the log file to check.
