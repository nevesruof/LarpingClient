Screenshots & Recorder

Keep a screenshot or record a whole session.

Screenshots#

Take a screenshot with Minecraft’s screenshot key, normally F2. The client uses numbered ScreenShot-N names, an animated preview and chat actions for copying and previewing the result.

Recorder#

Enable Recorder for an ongoing recording. Options include frame rate, resolution, encoder, quality and desktop audio. Windows capture reads the Minecraft framebuffer, so windowed and F11 modes use the same capture path.

Your recordings#

Use the Recordings button to browse captures and clips. Recorder is for a recording you explicitly start and stop; Instant Replay keeps a rolling 30-second history.

Audio and resource use#

Desktop audio uses the default Windows output device. Recorder and Replay cannot be active together. Enable capture only when needed, and check the saved file before relying on a recording.
