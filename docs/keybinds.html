Keybinds

Default keys and where to change them.

All Larp keys are in Options → Controls → Key Binds → Larp Client. Mod toggles can also be set from each mod's settings page.

ActionDefault
Open the client menuRight Shift
Zoom (hold)C
Open the HUD editorNot bound
Music: play / pauseNot bound
Music: next / previousNot bound
Toggle any modNot bound, set it on the mod's page

Turn on Hotbar Keybinds to see the key bound to each hotbar slot, even if they are 1 2 3 4 G R, in the corner of every slot.
