Keybinds

Useful defaults and your own shortcuts.

Useful default keys#

ActionDefaultNotes
Open client menuRight ShiftRebind in Minecraft Controls.
Save a 30-second clipF8Enable Instant Replay and wait for its buffer.
Show shulker contentsLeft ShiftHover a shulker; Shulker Preview must be enabled.
Take a screenshotF2Uses Minecraft’s screenshot key.

Choose your own keys#

Go to Options → Controls → Key Binds → Larp Client. Module toggle binds, the clip key and shulker preview key are configurable. Check for conflicts if an action does not respond.
