Changelog

The 0.14 release line and recent refinements.

0.14.1 · Sound for your moments#

  • Desktop audio in manual and automatic 30-second clips.
  • Timestamped stereo audio history and joint audio/video trimming.
  • AAC audio in exported MP4 files.
  • Clear notifications if desktop capture is unavailable.

0.14.0 · A closer look#

  • NEW: Performance Monitor with frame-time graph, 1% lows, P95 and memory.
  • NEW: Instant Replay, a rolling 30-second video buffer with a configurable save key and automatic kill clips.
  • NEW: In-menu previews for Kill Efects.

0.13.x · Expression and refinement#

  • A dedicated Kill Efects section with exclusive Tralalero and Samurai animations.
  • Cached and streamed geometry, fewer allocations and bounded capture/export paths.
  • Shulker Preview, Item Details, Inventory Alert, Light Meter and expanded Lyrics options.
  • Recorder capture improvements, including the framebuffer path for F11.
  • Updated Discord application identity, already built in.

Menu and quality-of-life improvements#

  • Emblem-focused title screen, player pose and shared out-of-world backgrounds.
  • Server and music artwork with Larp fallback images.
  • Profile deletion and a confirmed configuration reset.
  • Direct text editing, custom accent selection and Clear/Paste feedback.
  • Numbered screenshots, animated previews, event macros and English/Spanish selection.

Some changes originated in earlier development builds. These notes group the current release line rather than asserting exact dates for every change.
