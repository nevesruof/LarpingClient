Installation

Get set up with Larp Client 0.14.1.

Before you start#

  • Minecraft 1.21.11.
  • Fabric Loader 0.20.1 or newer and Fabric API for the same Minecraft version.
  • Java 21.
  • The Larp Client JAR, available through private access.

Install in four steps#

  1. Request accessMessage iTake using the access section. There is no public client download on this website.
  2. Set up FabricInstall Fabric for Minecraft 1.21.11 in your preferred launcher.
  3. Add the modsPlace Fabric API and larp-client-0.14.1.jar in the instance’s mods folder.
  4. Launch and customizeStart the Fabric instance. Open Larp with Right Shift or from the title screen.

Updating an existing instance#

Close Minecraft, remove the previous Larp JAR and add the new one. Keep one Larp version in your mods folder. Back up your configuration before making large changes.

Desktop media features#

Music Player uses Windows media controls. Recorder, Instant Replay desktop audio and Music Beats use Windows-specific capture paths. Do not assume these features work on macOS or Linux.

Something did not start?#

Check the Minecraft version, Fabric API and Java version first. Then see Troubleshooting.
