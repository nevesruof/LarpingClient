Installation

Install Fabric, add Larp Client and Fabric API, and launch.

Larp Client is private for now. Message Take to get access and the jar.

Install in four steps#

  1. Install FabricDownload the Fabric installer, open it, pick Minecraft 1.21.11 and click Install. Keep "Create profile" checked.
  2. Open your mods folderPress Win + R, type %appdata%\.minecraft and press Enter. Create a folder called mods if it isn't there.
  3. Add the two modsPut the Larp Client jar (Take sends it to you when you get access) and Fabric API for 1.21.11 in mods.
  4. LaunchIn the Minecraft Launcher, choose the fabric-loader-1.21.11 profile and press Play. The Larp title screen means it worked.

Add Sodium, Lithium and Entity Culling to the same folder for a big FPS boost. Larp is made to run with them.

Prism, Modrinth App and others#

Create a new instance for Minecraft 1.21.11 with the Fabric loader, then add Fabric API and drop larp-client-0.9.5.jar into the instance's mods folder (usually under "Open folder").

Updating#

Delete the old larp-client-*.jar from mods and put the new one in. Your settings are kept, they live in the config folder.

macOS and Linux#

The mods folder is ~/Library/Application Support/minecraft/mods on macOS and ~/.minecraft/mods on Linux. Everything works except the Music Player, which reads Windows media controls.

It doesn't start#

  • Make sure Fabric API is the 1.21.11 build, not an older one.
  • Remove other clients or mods that replace the title screen and menus, then try again.
  • Still stuck? See Troubleshooting.
