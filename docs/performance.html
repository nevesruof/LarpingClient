Performance

Understand the cost of your setup.

NEW: Performance Monitor#

Enable HUD → Performance Monitor for frame times, FPS, 1% lows, P95 and memory use. These describe your current session; the website’s sample graph is illustrative.

Optional module profiling#

Profile module ticks measures the CPU cost of module tick handlers and highlights the most expensive one. It does not measure GPU work or all module rendering. Profiling starts off to avoid unnecessary work.

Rendering improvements#

Recent revisions reduce repeated allocations with streamed geometry, cached trigonometry and reusable cosmetic topology. Rounded shapes no longer need opaque corner masks. Cosmetics reuse prepared data instead of rebuilding everything on every frame.

Capture has a budget#

Frame capture uses a small reusable buffer pool. Instant Replay keeps compressed video segments and a fixed-size audio history. Only one clip export can be pending; export happens outside the render thread.

Find your balance#

  • Enable effects gradually and compare frame times in the same scene.
  • Lower cosmetic refresh rates or effect counts if your setup needs it.
  • Disable recording and replay when you are not using them.
  • Be mindful of blur, shaders, resolution and enabled visual effects.

No fixed FPS increase is guaranteed. Hardware, worlds and other mods affect the result. Automated tests are not a replacement for checking a real Windows gameplay session.
