Introduction

Larp Client is a visual client for Minecraft 1.21.11 built on Fabric.

Larp Client is a Fabric mod for Minecraft 1.21.11. It adds 63 modules (HUD elements, PvP info, visuals and 3D cosmetics), its own menus and a HUD editor. Everything it draws stays on your screen: it never changes how the game plays.

InstallationGet Larp running in about two minutes. The client menuTurn mods on, change settings and bind keys. All modulesEvery module and every setting, searchable. CosmeticsWings, hats, auras, capes and trails.

Requirements#

  • Minecraft 1.21.11 (Java Edition)
  • Fabric Loader 0.18.1 or newer
  • Fabric API for 1.21.11
  • Java 21 (the official Minecraft Launcher already includes it)

Larp Client is private and in development. To get it, message Take for access.

Larp is a Fabric mod, not a separate launcher like Lunar or Badlion. It runs inside the normal Minecraft Launcher, Prism, Modrinth App or any launcher that supports Fabric.
