HUD editor

Place every HUD element exactly where you want it.

Open it from Edit HUD at the bottom of the client menu, or bind a key for it in Controls. Every HUD module that's on shows up and can be dragged.

Moving elements#

  • Drag an element to move it. It snaps to the screen edges, the center and the edges of other elements, with guide lines.
  • Use the arrow keys to move the selected element by 1 pixel, or 10 with Shift.
  • Positions are saved relative to the screen, so they stay put when you resize the window or change the GUI scale.

Toolbar#

DoneSave and close.
ModsGo to the client menu to turn elements on or off.
GridShow a grid while you place things.
SnapTurn snapping on or off.
Reset allPut every element back in its default spot.

Styling elements#

Every HUD module shares the same style settings: Scale, Background, Background color, Corner radius, Text color, Chroma text, Font (Minecraft or Clean) and Text shadow.
