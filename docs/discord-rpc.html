Discord RPC

Show Larp Client, your server and the game version on Discord.

Discord RPC sets your Discord status while you play: the Larp logo, Larp Client, the server you're on (for example In eskmc.net), Multiplayer [1.21.11], how long you've been playing and two buttons.

Set it up#

  1. Create a Discord appGo to the Discord Developer Portal, click New Application and name it Larp Client. That name is what people see.
  2. Copy the Application IDIn game, open the menu → RPC → Application ID and paste it.
  3. Upload the logoIn your app, go to Rich Presence → Art Assets and upload a transparent PNG named logo.
  4. Set the buttonsChange the two button texts and links. Links must start with https://.

Discord doesn't let you click your own buttons. Other people see them and can use them.

If your launcher also shows a Discord status (for example the Modrinth App), turn it off there so only Larp's shows.
